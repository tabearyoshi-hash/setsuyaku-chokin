# 節約貯金

節約・我慢できたら ＋、贅沢・無駄遣いしたら － で記録し、合計を見て節約を図るWebアプリです。

- アプリ: https://tabearyoshi-hash.github.io/setsuyaku-chokin/
- 現在の版: v0.14（月を切り替えて先月の内訳を見る）
- データはブラウザの localStorage に保存されます

## iPhone ウィジェットに合計を表示する（Scriptable経由）

Webアプリ単体では iOS ウィジェットは作れないため、Scriptable を仲介します。

1. アプリの「あとで使う用」カードで「📱 ウィジェット用ファイルを保存」を押す
2. 保存先に **iCloud Drive の「Scriptable」フォルダ**を選び、`setsuyaku-widget.json` のまま保存する
3. Scriptable アプリで `widget-scriptable.js` を新規スクリプトとして貼り付ける
4. ホーム画面に Scriptable ウィジェット（小／中）を置き、このスクリプトを選ぶ
5. 表示を更新するには、**ウィジェットをタップ → 光っている「ウィジェット用ファイルを保存」をタップ**の2タップで上書きする。ウィジェットは iOS が定期的に更新します（約30分後の更新をスクリプトからお願いしていますが、タイミングを決めるのは iOS で保証はありません）。アプリにはウィジェット用ファイルの最終保存日時（「最終保存：11/18 03:05」）も表示されます

### 更新をさらに楽にする（初回だけの設定）

iPhone の「設定 → Safari → ダウンロード」で保存先を「その他」から **iCloud Drive の「Scriptable」フォルダ**にしておくと、以後「ウィジェット用ファイルを保存」を押したとき保存先を毎回選ばずに済みます（Safari のダウンロード保存先は設定アプリから変えられる仕組みです）。

ショートカットアプリで「URLを開く」に `https://tabearyoshi-hash.github.io/setsuyaku-chokin/?widget=1` を入れたショートカットを作ると、ホーム画面から1タップでウィジェット欄が開き、そのまま保存ボタンを押せます。**開いただけで自動保存はできません**。iOS Safari はユーザー操作なしに JavaScript からダウンロードを開始させないため、保存は必ずボタンを押す形になります（完全自動の更新は Web アプリ＋Scriptable の組み合わせではできない制約です）。

毎朝決まった時刻にアプリを開くよう自動化すると、保存し忘れを防げます。ショートカットアプリの「オートメーション」で「時刻」（例：毎朝 7:00）→ アクション「URLを開く」に上の `?widget=1` 付き URL → 実行方法を「すぐに実行」（iOS 16以前は「実行の前に尋ねる」をオフ）にすると、確認なしでその時刻にアプリが開きます。開いたら光っている保存ボタンを1タップするだけです。朝の決まった時間にアプリが開くのがわずらわしい場合は、この自動化は使わなくて構いません（あくまで任意の手順です）。

- 小サイズ：合計・目標までの残り（または達成／マイナス）・更新日時
- 中サイズ：小サイズの内容 ＋ 今日・今月・＋合計・－合計・進み具合バー
- 最終保存から1日以上たっていると、小／中どちらにも「⚠ ○日以上前のデータです」の警告が出ます（古い合計だと気づかずに見てしまうのを防ぐため。v0.10）
- ファイルがない／読めない場合は、ウィジェット内に案内を表示します
- 実機での動作は未検証です（VM でのスタブ検証のみ）

## 版の履歴

- v0.14（2026-11-23 夜間）：月切り替えで先月の内訳を見る。残高カードの内訳の上に「‹ 前月」「2026年11月」「翌月 ›」の切り替えを付け、表示中の月の合計（「今月」の欄）とカテゴリ別内訳がその月に切り替わる（見出しも「10月のカテゴリ別」のように変わる）。過去の月を見ているときは「今月に戻る」ボタンが出る。「翌月」は今月では押せない（未来の月には進めない）。表示だけの切り替えで、保存データ（記録・JSON・ウィジェット用JSON）の形は変えていない。開き直すと今月に戻る。家計簿アプリの月レポートで「◀ ▶ で月を切り替える」流儀（Moneypet「上の ◀ ▶ で月を切り替えます」、ポケマネ「月を切り替えて収入と支出を一覧表示」）に沿ったもの。
- v0.13（2026-11-22 夜間）：連続記録日数（ストリーク）の表示。ホームの残高カードに、記録がある日が今日から何日連続しているか「🔥 連続記録 N日目」が出る。今日まだ記録がなくても昨日まで続いていれば昨日の分まで数え、最後の記録が一昨日以前なら表示は消える（0日とは表示しない）。同じ日の複数記録は1日分、未来の日付の記録は数えない。表示だけの集計で、保存データ（記録・JSON・ウィジェット用JSON）の形は変えていない。設定の「表示するもの」に「連続記録日数」チップを追加し、ON／OFFできる（新しい設定 `showStreak` は既定ONで、旧設定で開いても表示される）。節約系アプリで連続記録を数える流儀（Beyond Budget「連続して予算を立てた日数を数える」、No Spend Streak「毎日の節約ストリークを作る」）に沿ったもの。
- v0.12（2026-11-21 夜間）：カテゴリ別内訳のみの表示に対応。表示設定を分離し、「今日・今月などの内訳」と「カテゴリ別内訳」を別々にON／OFFできるようにした（設定の「表示するもの」に「カテゴリ別内訳」チップを追加）。「今日・今月などの内訳」をOFFにして「カテゴリ別内訳」をONにすると、カテゴリ別だけが残る。両方ON（従来どおり）・両方OFFも選べる。新しい設定 `showCatBreakdown` は既定ONで、旧設定（このキーがないデータ）で開いてもカテゴリ別は表示される。保存データ（記録・JSON・ウィジェット用JSON）の形は変えていない。
- v0.11（2026-11-20 夜間）：今月のカテゴリ別内訳表示。ホームの内訳の下に「今月のカテゴリ別」が出て、カテゴリごとに ＋合計・－合計・差し引きが見える（差し引きの大きい順。先月の記録は含めない。カテゴリ未選択は「カテゴリなし」にまとめる）。設定の「今日・今月などの内訳」をOFFにすると一緒に隠れる。表示だけの集計で、保存データの形は変えていない。家計簿アプリの月レポートでカテゴリごとの内訳を見る流儀（Moneypet「カテゴリごとの内訳がグラフで見られます」、缶詰家計簿「支出の内訳やカテゴリーごとの消費額などをわかりやすく把握できます」）に沿ったもの。
- v0.10（2026-11-19 夜間）：ウィジェット第四歩。ウィジェットに古いデータの警告を追加。最終保存から1日以上たっていると小／中どちらにも「⚠ ○日以上前のデータです」（琥珀色）が出る。updatedAt がない／読めないときは警告なしで表示を続ける。ショートカットの時刻オートメーションで毎朝 `?widget=1` 付き URL を開く手順を README に追加（「すぐに実行」なら確認なしで開く。出典：code-rebuild.com「iPhoneで決まった時間にアプリ自動起動」、fwrdsms.com「すぐに実行と確認後に実行の違い」。開くだけでは保存されないため、光った保存ボタンの1タップは残る）。
- v0.9（2026-11-18 夜間）：ウィジェット第三歩。ウィジェットのタップ先を `?widget=1` にし、タップするとアプリが設定タブのウィジェット欄で開いて保存ボタンが光る（2タップで更新できる形）。保存の blob URL 破棄を 1 秒後から 60 秒後に延ばした（iOS Safari はダウンロード確認ダイアログでユーザーが「ダウンロード」を押してから blob を読むため、1 秒で破棄すると押す前に URL が死んで保存されないことがある）。
