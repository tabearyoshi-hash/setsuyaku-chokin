# 節約貯金

節約・我慢できたら ＋、贅沢・無駄遣いしたら － で記録し、合計を見て節約を図るWebアプリです。

- アプリ: https://tabearyoshi-hash.github.io/setsuyaku-chokin/
- 現在の版: v0.19（カテゴリ別予算の合計表示）
- データはブラウザの localStorage に保存されます

## iPhone ウィジェットに合計を表示する（Scriptable経由）

Webアプリ単体では iOS ウィジェットは作れないため、Scriptable を仲介します。

1. アプリの「あとで使う用」カードで「📱 ウィジェット用ファイルを保存」を押す
2. 保存先に **iCloud Drive の「Scriptable」フォルダ**を選び、`setsuyaku-widget.json` のまま保存する
3. Scriptable アプリで `widget-scriptable.js` を新規スクリプトとして貼り付ける
4. ホーム画面に Scriptable ウィジェット（小／中）を置き、このスクリプトを選ぶ
5. 表示を更新するには、**ウィジェットをタップ → 光っている「ウィジェット用ファイルを保存」をタップ**の2タップで上書きする。ウィジェットは iOS が定期的に更新します（約30分後の更新をスクリプトからお願いしていますが、タイミングを決めるのは iOS で保証はありません）。アプリにはウィジェット用ファイルの最終保存日時（「最終保存：11/18 03:05」）も表示されます

### 更新をさらに楽にする（初回だけの設定）

iPhone の「設定 → Safari → ダウンロード」で保存先を「その他」から **iCloud Drive の「Scriptable」フォルダ**にしておくと、以後「ウィジェット用ファイルを保存」を押したとき保存先を毎回選ばずに済みます（Safari のダウンロード保存先は設定アプリから変えられる仕組みです）。

ショートカットアプリで「URLを開く」に `https://tabearyoshi-hash.github.io/setsuyaku-chokin/?widget=1` を入れたショートカットを作ると、ホーム画面から1タップでウィジェット欄が開き、そのまま保存ボタンを押せます。**開いただけで自動保存はできません**。iOS Safari はユーザー操作なしに JavaScript からダウンロードを開始させないため、保存は必ずボタンを押す形になります（完全自動の更新は Web アプリ＋Scriptable の組み合わせではできない制約です）。

毎朝決まった時刻にアプリを開くよう自動化すると、保存し忘れを防げます。ショートカットアプリの「オートメーション」で「時刻」（例：毎朝 7:00）→ アクション「URLを開く」に上の `?widget=1` 付き URL → 実行方法を「すぐに実行」（iOS 16以前は「実行の前に尋ねる」をオフ）にすると、確認なしでその時刻にアプリが開きます。開いたら光っている保存ボタンを1タップするだけです。朝の決まった時間にアプリが開くのがわずらわしい場合は、この自動化は使わなくて構いません（あくまで任意の手順です）。

- 小サイズ：合計・目標までの残り（または達成／マイナス）・更新日時
- 中サイズ：小サイズの内容 ＋ 今日・今月・＋合計・－合計・進み具合バー
- 最終保存から1日以上たっていると、小／中どちらにも「⚠ ○日以上前のデータです」の警告が出ます（古い合計だと気づかずに見てしまうのを防ぐため。v0.10）
- ファイルがない／読めない場合は、ウィジェット内に案内を表示します
- 実機での動作は未検証です（VM でのスタブ検証のみ）
